# Skill: asm-check

Review and analyze assembly code generated by the Go compiler.

## When to Use

- Verifying compiler generates expected instructions
- Optimizing performance-critical code
- Writing assembly tests in `test/codegen/`
- Understanding low-level behavior
- Debugging code generation issues

## Viewing Assembly

```bash
# Print assembly for package
go build -gcflags='-S' <package>

# Print assembly for specific function (cleaner)
go tool compile -S file.go

# With optimizations disabled
go build -gcflags='-N -l -S' <package>

# Specific architecture
GOARCH=arm64 go build -gcflags='-S' <package>
```

## Assembly Test Files

Location: `test/codegen/`

Format:
```go
func example(x int) int {
    // amd64:"IMULQ"
    // arm64:"MUL"
    return x * 5
}
```

### Directive Syntax
```go
// amd64:"PATTERN"           // must contain PATTERN
// amd64:-"PATTERN"          // must NOT contain PATTERN
// amd64:"PAT1","PAT2"       // must contain both
// amd64/v1:"PATTERN"        // specific microarchitecture
```

### Running Codegen Tests
```bash
go test cmd/internal/testdir -run='Test/codegen'
```

## Common Instructions

### AMD64
| Op | Instruction | Notes |
|----|-------------|-------|
| Add | `ADDQ` | 64-bit add |
| Multiply | `IMULQ` | 64-bit signed multiply |
| Shift | `SHLQ`, `SHRQ` | Left/right shift |
| Load | `MOVQ` | 64-bit load |
| Compare | `CMPQ` | 64-bit compare |
| Branch | `JE`, `JNE`, `JL` | Conditional jump |

### ARM64
| Op | Instruction | Notes |
|----|-------------|-------|
| Add | `ADD` | Add |
| Multiply | `MUL` | Multiply |
| Shift | `LSL`, `LSR` | Left/right shift |
| Load | `MOVD` | 64-bit load |
| Compare | `CMP` | Compare |
| Branch | `BEQ`, `BNE` | Conditional branch |

## Go Assembly Conventions

- `AX`, `BX`, `CX`, `DX` - General purpose (amd64)
- `SP` - Stack pointer
- `FP` - Frame pointer (arguments)
- `SB` - Static base (globals)
- `PC` - Program counter

## Pseudo-registers

```
FP - frame pointer: arguments and locals
PC - program counter: jumps and branches
SB - static base: global symbols
SP - stack pointer: top of stack
```

## Memory References

```
symbol+offset(SB)    // global
offset(SP)           // local on stack
offset(FP)           // function argument
```

## Writing Go Assembly

Files with `.s` extension in package directory.

```asm
// func Add(a, b int) int
TEXT ·Add(SB), NOSPLIT, $0-24
    MOVQ a+0(FP), AX
    ADDQ b+8(FP), AX
    MOVQ AX, ret+16(FP)
    RET
```
